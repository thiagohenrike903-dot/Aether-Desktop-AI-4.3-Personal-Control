# Prévias visuais — Aether 4.3

As capturas 4.3 foram renderizadas diretamente pelo renderer final em Chromium,
em vez de serem ilustrações recriadas. Projetos, conversas, operações, fontes e
métricas são fixtures locais usadas somente para documentar estados completos
da interface. Nenhuma fixture entra no aplicativo ou no banco do usuário.

- `Aether-4.3-Painel-Pessoal.png`: painel do perfil Trabalho, atalhos,
  projetos, automações, privacidade e saúde.
- `Aether-4.3-Foco-Timeline-Comparacao.png`: modo foco, timeline operacional,
  verificação, métricas e comparação A/B dentro da resposta.
- `Aether-4.3-Model-Lab.png`: duas respostas com o mesmo contexto, métricas,
  diferenças e notas manuais por critério.
- `Aether-4.3-Confianca-e-Auditoria.png`: integridade, filtros, exportação e
  comparação do estado anterior com o posterior.
- `Aether-4.3-Saude-e-Recuperacao.png`: disponibilidade, causas prováveis e
  reparos reversíveis.
- `Aether-4.3-Responsivo.png`: adaptação do painel para uma tela de 430×932.

Os arquivos 4.2 permanecem nesta pasta apenas como registro visual da versão
anterior.
